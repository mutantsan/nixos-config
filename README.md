# nixos-config

Personal NixOS configuration for a single machine, built to look and feel like
Omarchy 4.x. The Omarchy desktop is not reimplemented here — it is vendored via
[**nixarchy**](https://github.com/olafkfreund/nixarchy), which packages the real
upstream Omarchy tree (QuickShell shell, 22 themes, Hyprland Lua defaults, ~444
`omarchy-*` commands) as a Nix derivation and rewires its menus from `pacman` to
Nix.

## Layering — what lives where

| Layer | Repo | Mechanism |
|---|---|---|
| System + Omarchy desktop | **this repo** | flake → NixOS module + Home Manager module from nixarchy (`v4.0.3-1`) |
| Portable shell / editor / CLI (zsh, vim, atuin, bat, lsd) | [`dotfiles`](https://github.com/mutantsan/dotfiles) | GNU `stow`, re-run each rebuild by `home/cherry.nix` |
| `~/.bashrc` | nixarchy | owns it (Omarchy shell chain); dotfiles `bash` package is *not* stowed |
| Live desktop tweaks (Hyprland Lua, menu, theme) | `~/.config` on the machine | seeded by nixarchy, then edited in place; mirrored into `reference/` here |

`dotfiles` stays a separate repo — zero desktop config, used on macOS/WSL too.
Clone it manually once (`git clone git@github.com:mutantsan/dotfiles.git
~/dotfiles`); thereafter every `nixos-rebuild` re-stows it. It is **not**
auto-cloned because SSH keys aren't available during activation.

`~/.zshrc` comes from the stow'd dotfiles (cross-platform, oh-my-zsh based).
Home Manager does not manage zsh here — that would fight stow for the symlink.
oh-my-zsh + its external plugins are installed by hand, same as on Arch (see
`home/cherry.nix` for the exact clone commands).

## Repo layout

```
flake.nix                  inputs (nixpkgs, home-manager, nixarchy), one nixosConfiguration
flake.lock
hosts/
  nixos/
    configuration.nix      system config + nixarchy NixOS module
    hardware-configuration.nix   generated by `nixos-generate-config` at install (gitignored until real)
home/
  cherry.nix               Home Manager: nixarchy HM module, theme=nord, dotfiles re-stow
nixarchy-apps.nix          generated by `nixarchy-apply` from menu picks — commit it
reference/                 snapshot of the current Omarchy machine (see omarchy-state.md)
```

## Bring-up steps (on the new machine)

1. **Install NixOS by hand** (UEFI + systemd-boot — nixarchy requires UEFI,
   x86_64, and a wired keyboard if the disk is encrypted). Enable flakes.
2. `sudo nixos-generate-config` → copy the generated
   `hardware-configuration.nix` into `hosts/nixos/`.
3. Fill the `TODO`s in `hosts/nixos/configuration.nix`: hostname, timezone,
   `system.stateVersion` (match the installer), and `programs.nixarchy.flake`
   (the real on-disk path of this repo). Match `home.stateVersion` in
   `home/cherry.nix`.
4. nixarchy is already pinned to `v4.0.3-1` (matches Omarchy 4.0.3). Bump from
   <https://github.com/olafkfreund/nixarchy/releases> when you want a newer one.
5. `nix run github:olafkfreund/nixarchy#doctor` — pre-flight conflict check.
6. `git clone git@github.com:mutantsan/dotfiles.git ~/dotfiles`
7. `sudo nixos-rebuild switch --flake .#nixos`
8. Log out, pick the **Omarchy** (nixarchy) session, log back in.
9. `nix run github:olafkfreund/nixarchy#verify` from inside the session.

## After first boot — reproduce the personal layer

- **Apps**: pick them from `Install ▸ …` in the Omarchy menu (writes
  `~/.config/nixarchy/apps.nix`), run `nixarchy-apply`, then commit the
  regenerated `nixarchy-apps.nix`. Cross-check against
  `reference/packages-explicit.txt`.
- **Theme**: `programs.nixarchy.defaultTheme = "nord"` is already set; `omarchy
  theme set nord` to switch at runtime.
- **Hyprland overrides**: copy `reference/hypr/*.lua` into `~/.config/hypr/`
  (nixarchy will not overwrite an existing dir). Fix the hardcoded
  `/home/cherry` paths in `autostart.lua` / `bindings.lua` if the username
  differs.
- **Menu**: drop `reference/omarchy/omarchy-menu.jsonc` into
  `~/.config/omarchy/extensions/`.
- **Bar plugins**: reinstall the five in `reference/omarchy-state.md` via the
  menu / their repos.
- **dotfiles**: `git clone` it to `~/dotfiles` (step 6); `home/cherry.nix`
  re-stows `atuin bat lsd vim zsh` every rebuild. Not `bash` (nixarchy owns it),
  not `vscode` (stray root files).
- **Personal tools** not in nixpkgs (`clipboard-manager-ms`, `omarchy-sc`,
  `solr-status`, `tempie`): keep building them imperatively for now, or add
  flake packages later. Listed in `reference/omarchy-state.md`.

## Known gaps vs. the Arch machine

- Custom Basecamp packages (`omacalc`, `omawrite`, `tensaku`, `cliamp`,
  `tobi-try`, …) come from the vendored tree; any that fail to build degrade
  gracefully (menu entry prints a message instead of running).
- greetd/GDM cannot host the branded QML login screen; only SDDM gets it.
- TLP and power-profiles-daemon conflict on NixOS — this config uses
  power-profiles-daemon (the Omarchy default). Don't enable TLP.
- `programs.nixarchy` module options were verified against
  `modules/{nixos,home}.nix` at tag `v4.0.3-1`; re-check after bumping.

## Still unverified / do on the machine

- The whole flake can't evaluate until `hardware-configuration.nix` exists and
  the `stateVersion` TODOs are real.
- `nixarchy#doctor` catches the common conflicts (stale sessions, read-only
  `mimeapps.list`, small `/tmp`). Run it before the first `switch`.
- Font / CJK / emoji rendering — confirm after first boot; add packages to
  `fonts.packages` only if something's actually missing.
